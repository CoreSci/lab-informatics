# Lab Informatics

Parsers and workflow patterns for **open laboratory data standards**, built and tested on **synthetic data only**.

## Scope

- **Open standards only.** Formats with a published, openly available specification. JCAMP-DX (IUPAC) and mzML (HUPO-PSI) are implemented today; other open formats may be added later.
- **Synthetic data only.** Every sample file is generated by a script in this repository. Where a model compound is used, it is named and its masses are computed in the generator; no file is modelled on a real sample or instrument.

## Contents

| Path | What it is |
|---|---|
| [`data-decoders/jcamp-dx-reader/`](data-decoders/jcamp-dx-reader/) | Parser, validator and writer for JCAMP-DX, the open IUPAC spectral exchange format (AFFN and SQZ/DIF/DUP compression, X/Y-check integrity validation, CLI and unit tests), demonstrated on synthetic IR and UV-Vis spectra |
| [`data-decoders/mzml-reader/`](data-decoders/mzml-reader/) | Streaming, standard-library-only reader and validator for mzML, the open HUPO-PSI mass spectrometry format (base64 and zlib binary arrays, 32/64-bit floats, plain and indexed files, chromatograms; structural, array and index/checksum validation with coded findings; unit tests), demonstrated on a synthetic LC-MS run of caffeine and deliberately corrupted copies |

## Important Note

This repository contains **generic, illustrative examples only**. Each implementation is written from its public specification. It does not include proprietary logic, client-specific implementations, or content tied to any commercial product.
